# ItAcademyWarehouse

## Описание проекта
ItAcademyWarehouse — это проект, направленный на автоматизацию складского хозяйства на производственном предприятии. Программное обеспечение предназначено для создания автоматизированного рабочего места (АРМ) сотрудников склада. 

**Основные функции:**
- Управление пользователями и ролями.
- Работа с продукцией, плавками и сертификатами.
- Операции с накладными: приёмка, отгрузка и возврат продукции.
- Управление заказами клиентов.
- Работа с этикетками продукции.
- Обширный API для взаимодействия с данными справочников, взвешиваний и перераспределений.

**Архитектура:**
- Приложение разработано по трёхслойной архитектуре.
- Поддерживается аутентификация и авторизация на основе JWT-токенов и политик безопасности.
